## ✨ 核心功能

### 🔥 实时系统监控
- **设备信息**：精准识别特定设备型号（如 Redmi Turbo 3、OPPO Reno 5 Pro+）和处理器规格（骁龙 8s Gen 3、骁龙865）
- **CPU/GPU 监控**：实时显示CPU、GPU温度、负载、核心状态、CPU各核心频率、GPU利用率
- **内存管理**：精确到 GB 级别的内存使用分析，包括实际内存、ZRAM/Swap
- **电池健康**：电量百分比 + 健康度 + 循环次数 + 充电状态 + 电流 + 电压 + 功率
- **网络状态**：WiFi 信号强度实时监测
- **GPS**
### ⚡ 快速访问面板
一键直达关键监控模块：
- CPU 处理器（频率/核心/温度）
- GPS 定位状态
- 内存信息详情
- 网络状态诊断

### 🌓 专业设计体验
- 赛博紫色未来科技主题界面（完美适配 OLED 屏幕）
- 实时动态数据可视化
- 精准的硬件指标监测
